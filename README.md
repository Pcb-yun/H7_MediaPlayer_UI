# H7_MediaPlayer_UI

本项目为**个人研究学习用途**，基于 LVGL Editor 的 MediaPlayer 界面工程，导出的界面代码供 MediaPlayer 应用固件使用。

## 硬件平台

- 目标主控：STM32H723ZGT6
- 目标屏幕：240 x 240

> 注意：项目目前**暂不具备高可移植性**，部分配置与硬件环境强耦合，如需移植到其他平台需自行调整。
